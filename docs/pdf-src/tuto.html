2. Installer Raspberry Pi OS

  1. Téléchargez Raspberry Pi Imager : raspberrypi.com/software.
  2. Choisissez l'OS : Raspberry Pi OS Lite (64-bit).
  3. Réglages avancés (engrenage) : activez SSH, définissez un nom d'utilisateur et un mot de passe.
  4. Écrivez sur la carte microSD.
  5. Insérez la carte dans le Pi, branchez Ethernet puis l'alimentation. Attendez 2 minutes.

3. Se connecter en SSH

Ouvrez le Terminal (Mac : Cmd+Espace, tapez « Terminal » ; Windows : menu Démarrer › PowerShell). Trouvez le Pi :

ping raspberrypi.local

(ou lisez son adresse IP dans l'interface de votre box). Connectez-vous :

ssh votre_utilisateur@raspberrypi.local

Le mot de passe est invisible quand vous le tapez : c'est normal. Puis mettez le système à jour :

sudo apt update && sudo apt full-upgrade -y

4. Pi-hole : bloqueur de pubs

curl -sSL https://install.pi-hole.net | bash

Suivez l'assistant et notez le mot de passe de l'interface. Pour filtrer tout le réseau, dans l'interface de votre box (ex. http://192.168.1.254 pour une Bbox) › DHCP, remplacez le DNS principal par l'IP du Pi. Interface de Pi-hole : http://IP_DU_PI/admin.

Seuls les appareils qui utilisent le Pi comme DNS sont filtrés. Si vous ne changez pas le DNS de la box, vos appareils à la maison continuent d'utiliser celui de la box et ne sont pas filtrés ; seuls ceux qui passent par le VPN du Pi le sont. Si le Pi est éteint, un réseau configuré ainsi n'a plus de DNS.
Pi-hole ne se met pas à jour tout seul. Il rafraîchit ses listes de pubs chaque semaine et vérifie chaque jour si une version existe, mais ne l'installe pas. De temps en temps : 
sudo pihole -up
sudo pihole reloadlists
dig @127.0.0.1 doubleclick.net +short        # doit afficher 0.0.0.0
Le reloadlists est important : après une mise à jour, le blocage peut rester inactif tant que les listes ne sont pas rechargées.

5. WireGuard : VPN sécurisé

curl -L https://install.pivpn.io | bash

Choisissez WireGuard, port 51820. PiVPN peut utiliser Pi-hole comme DNS : c'est ce qui bloque les pubs sur votre téléphone hors de chez vous. Pour atteindre le réseau local depuis le VPN, éditez la configuration :

sudo nano /etc/wireguard/wg0.conf

Ajoutez après ListenPort (deux lignes) :

PostUp = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -A FORWARD -o wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -D FORWARD -o wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

Remplacez eth0 par wlan0 si le Pi est en Wi-Fi (vérifiez avec ip route | grep default). Puis, dans la box, redirigez le port 51820 en UDP vers l'IP du Pi, de préférence celle de son Ethernet. Créez un profil pour le téléphone et scannez le QR code avec l'app WireGuard (App Store) :

pivpn add -n MonTelephone
pivpn -qr MonTelephone
Si le Pi a à la fois Ethernet et Wi-Fi, il a deux adresses IP : vérifiez que la redirection de port de la box pointe sur la bonne avant de couper l'une des deux.

6. DuckDNS : DNS dynamique

Votre box change d'adresse publique de temps en temps. DuckDNS associe un nom fixe (votredomaine.duckdns.org) à votre adresse actuelle. Inscrivez-vous sur duckdns.org, choisissez un domaine et notez le jeton (token). Le jeton ne donne accès qu'à vos domaines DuckDNS, mais ne le partagez pas.

mkdir -p ~/duckdns
nano ~/duckdns/token          # collez uniquement le jeton, puis enregistrez
chmod 600 ~/duckdns/token
nano ~/duckdns/duck.sh

Contenu de duck.sh (le jeton est lu dans un fichier à part, jamais écrit dans le script) :

#!/bin/bash
TOKEN=$(cat ~/duckdns/token)
echo url="https://www.duckdns.org/update?domains=VOTRE_DOMAINE&token=${TOKEN}&ip=" | curl -s -o ~/duckdns/duck.log -K -
chmod 700 ~/duckdns/duck.sh
~/duckdns/duck.sh && cat ~/duckdns/duck.log     # doit afficher OK

Automatisez toutes les 5 minutes : crontab -e (choisissez 1 pour nano si on vous le demande) et ajoutez tout en bas :

*/5 * * * * ~/duckdns/duck.sh >/dev/null 2>&1

Sur l'iPhone, dans WireGuard, remplacez l'IP par votredomaine.duckdns.org:51820.

7. AnyDesk : contrôle du Mac à distance

Sur le Mac : téléchargez AnyDesk (anydesk.com/download), installez-le, puis accordez les permissions :

  • Réglages › Confidentialité › Accessibilité : ajoutez AnyDesk.
  • Réglages › Confidentialité › Enregistrement de l'écran : ajoutez AnyDesk.
  • AnyDesk › Réglages › Sécurité › définir un mot de passe (accès non surveillé) ; cochez « Démarrer AnyDesk à la connexion » et notez l'ID.

Sur iPad/iPhone : installez AnyDesk, entrez l'ID et le mot de passe. Sans les permissions macOS, AnyDesk affiche un écran noir.

8. Wake-on-LAN

Nécessite l'Ethernet. Sur le Mac : Réglages › Énergie › Réactiver pour l'accès au réseau. Dans AnyDesk, activez Wake-On-LAN dans les réglages : le Mac se rallume à distance.

9. Time Machine via le Raspberry Pi

La Time Capsule ne partage son disque qu'en AFP, que macOS 27 ne gère plus. Le Pi monte la capsule en AFP et la repartage en SMB : le Mac sauvegarde en SMB à travers le Pi. L'installation complète et le dépannage sont détaillés dans le guide TimeCapsule_RPi_Bridge_Guide_FR_EN.pdf ; voici l'essentiel.

  1. Time Capsule : dans Utilitaire AirPort, renommez le disque sans espaces (ex. AirPortTimeCapsule) et notez son mot de passe.
  2. Installer : téléchargez le zip Mac ou Windows depuis la page GitHub du projet (dossier installers) et lancez-le (double-clic), ou, sur le Pi : 
    sudo apt install -y git
git clone https://github.com/DevTipsy/timecapsule-rpi-bridge.git
cd timecapsule-rpi-bridge && sudo bash install.sh
  3. Répondre aux questions : IP de la capsule, nom du volume, utilisateur Samba, utilisateur AFP (souvent vide), puis les mots de passe, saisis directement sur le Pi.
  4. Sur le Mac : Réglages Système › Général › Time Machine › + › choisissez « TimeMachine » sur le Pi, entrez l'utilisateur et le mot de passe Samba.
Ce qui change par rapport à la première version de ce guide : plus aucun mot de passe en clair (chiffré par systemd-creds) ; surveillance par timers systemd (au lieu de cron) qui répare le montage tout seul en ≈ 80 s ; journal de chaque panne avec l'état avant/après et la durée de connexion.
sudo timecapsule-ctl status     # état actuel
sudo timecapsule-ctl report     # historique des pannes et leurs causes
sudo timecapsule-ctl logs -f    # journal en direct
sudo timecapsule-ctl mount      # remonter à la main (demande le mot de passe au terminal)
À savoir : la première sauvegarde est très longue (plusieurs jours) ; gardez 100 Go libres sur la capsule ; ne gardez qu'une destination Time Machine pour la capsule (celle du Pi).

10. Sécurité

Clés SSH (connexion sans mot de passe)

Sur chaque Mac :

ssh-keygen -t ed25519 -C "description@machine"
ssh-copy-id utilisateur@IP_DU_PI
ssh utilisateur@IP_DU_PI          # doit se connecter sans mot de passe

Interdire ensuite les mots de passe SSH

Gardez une session SSH ouverte pendant toute la manipulation, au cas où il faudrait revenir en arrière.

Sur Raspberry Pi OS, sshd lit d'abord les fichiers de /etc/ssh/sshd_config.d/ et garde la première valeur rencontrée. Ajouter PasswordAuthentication no à la fin de sshd_config est donc souvent sans effet, car un fichier comme 50-cloud-init.conf impose yes avant. La bonne méthode : un fichier qui passe en premier.

sudo bash -c 'printf "PasswordAuthentication no\nPubkeyAuthentication yes\n" > /etc/ssh/sshd_config.d/00-keys-only.conf'
sudo sshd -t && sudo systemctl restart ssh
sudo sshd -T | grep -E "passwordauthentication|pubkeyauthentication"     # doit afficher "no" puis "yes"

Autres bonnes pratiques

  • Mises à jour : sudo apt update && sudo apt full-upgrade régulièrement ; sudo pihole -up pour Pi-hole.
  • Ne laissez ouvert que ce qui sert : sudo ss -tulnp liste les ports en écoute ; désactivez ce que vous n'utilisez pas (ex. un serveur AFP, un serveur d'impression, un bureau distant).
  • Aucun mot de passe en clair dans un script ou une commande : saisissez-les au clavier ou utilisez un fichier en chmod 600. Si un mot de passe a été exposé, changez-le.
  • sudo timecapsule-ctl audit vérifie les mots de passe en clair, les permissions, SSH, les ports ouverts et les mises à jour en attente.

11. Accès aux fichiers depuis l'iPhone en 4G/5G

  1. Activez le VPN WireGuard.
  2. App Fichiers › ⋯ › Se connecter au serveur.
  3. Entrez smb://IP_DU_PI/TimeMachine.
  4. Utilisateur et mot de passe Samba.
